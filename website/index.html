隐私安全

你的记忆，只属于你

从架构层面杜绝云端上传，四级隐私隔离体系，零知识证明技术确保数据所有权完全在你手中。

🌐

PUBLIC

公开级记忆，可被任何模块和 Agent 访问，用于通用知识和公开信息。

  • ✓ 全模块可读
  • ✓ 跨 Agent 共享
  • ✓ 可导出同步
🏠

INTERNAL

内部级记忆，仅同一 Agent 会话内可访问，默认隐私级别。

  • ✓ 同 Agent 可读
  • ✓ 会话内可用
  • ✗ 禁止跨 Agent
🔐

PRIVATE

私密级记忆，高度敏感数据，需显式授权才能访问，全程审计追踪。

  • ✓ 显式授权访问
  • ✓ 完整审计日志
  • ✗ 禁止自动召回
🛡️

STRICT

严格级记忆，物理隔离存储，最高级别保护，仅用户本人可解锁。

  • ✓ 物理隔离存储
  • ✓ 二次验证解锁
  • ✓ 零知识证明
🔒

AES-256-GCM

军用级加密强度，PBKDF2 密钥派生，每条记忆独立加密

🚫

零云端依赖

架构层面禁用云端上传，完全本地化运行，离线可用

📝

完整审计

所有访问操作均有不可篡改的审计日志，随时可追溯

🧩

零知识证明

验证记忆存在性而不泄露内容，支持隐私计算场景

快速上手

几分钟内 集成使用

简洁的 API 设计，丰富的适配器，无论是 Python 项目还是 Agent 平台，都能轻松接入。 

# 克隆仓库
git clone https://github.com/opok-ops/MindForge.git
cd MindForge

# 初始化（生成加密密钥）
python cli/main.py init

# 添加第一条记忆
python cli/main.py add "MindForge v5.0 真的太强了！" --category tech --importance high

# 启动 Web UI
python cli/main.py serve
from MindForge import MindForge, PrivacyLevel, Importance

# 初始化记忆系统
memory = MindForge(
    db_path="./data/memory.db",
    encrypted=True,
)

# 添加记忆
entry = memory.add(
    content="用户喜欢用 Python 进行开发",
    category="preferences",
    tags=["python", "开发"],
    privacy=PrivacyLevel.PRIVATE,
    importance=Importance.HIGH,
)

# 获取记忆
result = memory.get(entry.id)
print(result.content)
from MindForge import RecallConfig

# 语义搜索
results = memory.search(
    query="关于数据库优化的建议",
    config=RecallConfig(
        max_results=10,
        min_relevance=0.7,
        include_categories=["tech", "work"],
    )
)

# 知识图谱关联检索
related = memory.graph_traverse(
    entity="数据库优化",
    depth=2,
)

print(f"找到 {results.total} 条相关记忆")
for item in results:
    print(f"[{item.relevance:.2f}] {item.content[:50]}")
# 在 OpenClaw 配置中启用 MindForge
# config.yaml
memory:
  adapter: MindForge
  adapter_config:
    db_path: ~/.MindForge/data/store/memory.db
    key_file: ~/.MindForge/data/.key
    encrypted: true
    default_privacy: INTERNAL
    auto_consolidate: true

# 或者使用 CLI 配置
openclaw config set memory.adapter MindForge
openclaw config set memory.encrypted true
openclaw config set memory.auto_consolidate true

# 重启 OpenClaw 生效
openclaw restart
